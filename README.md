# Telegram-бот для заказов

## Настройка

1. Создайте бота через `@BotFather` и получите токен.
2. Узнайте свой Telegram ID, например через `@userinfobot`.
3. Скопируйте `.env.example` в `.env` и заполните `TELEGRAM_BOT_TOKEN` и `ADMIN_CHAT_ID`.
4. Установите зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   ```

5. Запустите бота:

   ```powershell
   python bot.py
   ```

## Публикация в интернете

Проще всего разместить сайт и бота вместе на Render:

1. Загрузите папку проекта в GitHub.
2. В Render создайте Blueprint из репозитория и выберите `render.yaml`.
3. В настройках сервиса задайте `TELEGRAM_BOT_TOKEN` и `ADMIN_CHAT_ID`.
4. После деплоя откройте выданный Render адрес вида `https://ваш-сервис.onrender.com`.

Render сохранит `orders.db` на постоянном диске. Не добавляйте `.env` в GitHub.

Пользователь отправляет боту описание заказа текстом. Администратор получает заявку с кнопками «Принять» и «Отклонить». Решение сохраняется в `orders.db`, а клиент получает уведомление в чат.
